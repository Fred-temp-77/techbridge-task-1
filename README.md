**THE DESIGN IDEA**

The design was based on basic UI designs, with a bit of creativity added, and the main colours came from the logo.


**WHAT WAS BUILT**

A responsive homepage for TechBridge that highlights the organization's mission, core programs, available internships, and portal options for applications or community engagement. This project serves as a practical assessment to demonstrate the intern's ability to create a well-structured, semantic HTML layout and style it using responsive, modern CSS.


**WHAT WAS LEARNED**
- Working without frameworks is far more complicated than I expected.
- Coming up with a design that makes sense and looks good is not easy.
- CSS Animations
- Another syntax for writing Media Queries


**CHALLENGES ENCOUNTERED**
- Coming up with a good design.
- Clashes with the width of the navigation and the screen.
